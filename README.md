# Tiff AI

Tiff AI is Trendify's AI assistant, built for Android using Kotlin and Jetpack Compose.

The project aims to bring Tiff's AI experience to Android through a native mobile application, with model selection, account management and conversation history.

## Features

- **AI Chat:** A native chat interface built with Jetpack Compose.
- **Model Selection:** Switch between Tiff Normal, Tiff Lite, Aurelius and Llull.
- **Account Management:** Foundation for user authentication and account settings.
- **Chat History:** Conversation history interface.
- **Secure Backend Integration:** Designed to connect to Trendify's approved backend API without exposing model-provider credentials in the application.
- **Modern Android UI:** Material 3 components and a responsive mobile layout.

## Supported Models

| Model | Purpose |
| --- | --- |
| Tiff Normal | Free everyday AI assistance |
| Tiff Lite | Lightweight AI tasks |
| Aurelius | Advanced reasoning |
| Llull | Intelligence through connected knowledge |

Model availability and capabilities depend on Trendify's backend configuration.

## Technology Stack

- Kotlin
- Jetpack Compose
- Material 3
- AndroidX ViewModel
- Kotlin Coroutines and StateFlow
- Gradle
- GitHub Actions

## Getting Started

### Requirements

- Android Studio
- JDK 17
- Android SDK 35
- Android device or emulator running Android 7.0 or later
